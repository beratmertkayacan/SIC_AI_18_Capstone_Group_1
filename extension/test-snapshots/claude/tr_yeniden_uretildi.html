Claude responded: Python'da bir listeyi ters çevirmenin iki yaygın yolu şunlar:

Python’da bir listeyi ters çevirmenin iki yaygın yolu şunlar:

1. Dilimleme ile (yeni bir liste üretir)

python
sayilar = [1, 2, 3, 4, 5]
ters = sayilar[::-1]

print(ters)     # [5, 4, 3, 2, 1]
print(sayilar)  # [1, 2, 3, 4, 5]  (orijinal liste değişmedi)

[::-1] ifadesi listeyi sondan başa doğru birer adım ilerleyerek okur ve sonucu yeni bir liste olarak döndürür. Orijinal liste olduğu gibi kalır.

2. reverse() metodu ile (listeyi yerinde değiştirir)

python
sayilar = [1, 2, 3, 4, 5]
sayilar.reverse()

print(sayilar)  # [5, 4, 3, 2, 1]

reverse() listenin kendisini değiştirir ve None döndürür. Bu yüzden ters = sayilar.reverse() yazarsan ters içinde None kalır.

Orijinal listeye ihtiyacın varsa dilimleme, ek bellek kullanmadan listeyi doğrudan değiştirmek istiyorsan reverse() daha uygun olur.
