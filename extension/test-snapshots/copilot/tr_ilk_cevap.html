Python'da bir listeyi nasıl ters çeviririm?
Copilot said:

Python'da bir listeyi ters çevirmek için birkaç yaygın yöntem vardır:

1. reverse() metodu (listeyi yerinde değiştirir)

Python
liste = [1, 2, 3, 4, 5]
liste.reverse()
 
print(liste)
# [5, 4, 3, 2, 1]

2. Dilimleme ([::-1]) ile yeni bir liste oluşturmak

Python
liste = [1, 2, 3, 4, 5]
ters_liste = liste[::-1]
 
print(ters_liste)
# [5, 4, 3, 2, 1]

Orijinal liste değişmez:

Python
print(liste)
# [1, 2, 3, 4, 5]

3. reversed() fonksiyonu

Python
liste = [1, 2, 3, 4, 5]
ters_liste = list(reversed(liste))
 
print(ters_liste)
# [5, 4, 3, 2, 1]

Özet:

  • liste.reverse() → Orijinal listeyi değiştirir.
  • liste[::-1] → Yeni ters liste oluşturur (en kısa ve yaygın yöntemlerden biri).
  • reversed(liste) → Ters sırada bir iterator döndürür; genellikle list() ile kullanılır.
