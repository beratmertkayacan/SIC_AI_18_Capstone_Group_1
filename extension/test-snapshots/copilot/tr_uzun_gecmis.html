Ortak Algoritma

Aslında tüm dillerde temel mantık aynıdır:

Plain Text
[1, 2, 3, 4, 5]
 
1 ↔ 5
2 ↔ 4
 
↓
 
[5, 4, 3, 2, 1]

Buna "Two Pointers (iki işaretçi)" yöntemi denir ve hemen hemen bütün programlama dillerinde çalışır.

Mülakatlarda genellikle sizden hazır fonksiyonları kullanmadan şu algoritmayı yazmanız beklenir:

Plain Text
sol = 0
sağ = son_indeks
 
while sol < sağ:
yer değiştir
sol++
sağ--

Bu yüzden Python'daki reverse(), JavaScript'teki reverse(), C++'taki std::reverse() gibi fonksiyonlar aslında arka planda benzer mantıklarla çalışır.

Eğer "gerçek implementasyon" derken std::reverse()'ün arkasındaki mantığı kastediyorsan, standard library'nin gerçek kodu derleyiciye göre değişir (libstdc++, libc++, MSVC STL). Ama temel algoritma aşağı yukarı şöyledir:

C++
template <typename BidirectionalIterator>
void reverse(BidirectionalIterator first,
BidirectionalIterator last)
{
while ((first != last) && (first != --last))
{
std::iter_swap(first, last);
++first;
}
}

Bu kodun çalışma mantığı:

Plain Text
[1, 2, 3, 4, 5]
 
first -> 1
last -> 5

1. Tur

Plain Text
1 ↔ 5

Sonuç:

Plain Text
[5, 2, 3, 4, 1]

2. Tur

Plain Text
2 ↔ 4

Sonuç:

Plain Text
[5, 4, 3, 2, 1]

3. Tur

Ortaya gelinir:

Plain Text
3

Durulur.

Bir std::vector<int> için elle yazarsak:

C++
#include <iostream>
#include <vector>
 
void reverse(std::vector<int>& v)
{
size_t left = 0;
size_t right = v.size() - 1;
 
while (left < right)
{
std::swap(v[left], v[right]);
 
++left;
--right;
}
}
 
int main()
{
std::vector<int> nums = {1, 2, 3, 4, 5};
 
reverse(nums);
 
for (int x : nums)
std::cout << x << " ";
}

Çıktı:

Plain Text
5 4 3 2 1

Bellek görünümü:

Plain Text
Başlangıç:
 
index: 0 1 2 3 4
value: 1 2 3 4 5
 
swap(0,4)
 
index: 0 1 2 3 4
value: 5 2 3 4 1
 
swap(1,3)
 
index: 0 1 2 3 4
value: 5 4 3 2 1

Bu yaklaşımın güzel yanı:

  • Ekstra dizi oluşturmaz.
  • Ekstra bellek kullanımı O(1)'dir.
  • Çalışma süresi O(n)'dir.
  • std::reverse() da özünde bu sınıftaki bir algoritmayı uygular.

Daha da ilginci, C++20'de std::reverse() yalnızca vector için değil, list, deque, array ve iterator sağlayan pek çok veri yapısı için aynı algoritmik fikri kullanacak şekilde jenerik yazılmıştır. Bu yüzden STL'nin gücü, algoritmanın veri yapısından ayrılmış olmasından gelir.

Peki std::reverse Nasıl Kullanılır?

Aynı işi STL ile:

C++
#include <algorithm>
#include <vector>
#include <iostream>
 
int main()
{
std::vector<int> sayilar = {10, 20, 30, 40, 50};
 
std::reverse(sayilar.begin(), sayilar.end());
 
for (int x : sayilar)
{
std::cout << x << " ";
}
}

Çıktı:

Plain Text
50 40 30 20 10

Burada:

C++
sayilar.begin()

ilk elemanı,

C++
sayilar.end()

son elemandan sonraki konumu gösterir.

STL içinde bunun yaptığı şey de temelde:

C++
while (left < right)
{
swap(*left, *right);
++left;
--right;
}

mantığından ibarettir.

Yani std::reverse aslında sihirli bir yapı değil; senin yazdığın two-pointers algoritmasının jenerik (generic) ve optimize edilmiş bir sürümüdür.
