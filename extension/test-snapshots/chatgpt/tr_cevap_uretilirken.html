Python'da bir listeyi nasıl ters çeviririm?

ChatGPT dedi:ChatGPT

Python'da bir listeyi tersine çevirmek için birkaç farklı yöntem kullanabilirsin.

1. reverse() – Listeyi doğrudan ters çevirir

Python
liste = [1, 2, 3, 4, 5]

liste.reverse()

print(liste)
# [5, 4, 3, 2, 1]

  • Orijinal listeyi değiştirir.

  • Yeni bir liste oluşturmaz.

2. [::-1] – Slicing yöntemi

Python
liste = [1, 2, 3, 4, 5]

ters_liste = liste[::-1]

print(ters_liste)
# [5, 4, 3, 2, 1]

  • Orijinal listeyi değiştirmez.

  • Yeni bir liste oluşturur.

3. reversed() – Ters sıralı iterator döndürür

Python
liste = [1, 2, 3, 4, 5]

ters_liste = list(reversed(liste))

print(ters_liste)
# [5, 4, 3, 2, 1]

  • Orijinal listeyi değiştirmez.

  • list() ile tekrar listeye dönüştürebilirsin.
